home router rewrites the L3 source IP (NAT) and L4 source Port (NAPT), recomputing both checksums.
Return traffic: the home router rewrites the destination IP and Port back to the PC.
Data is never changed in transit, and with HTTPS the lower layers can't even read it. ^1r0qWppj
