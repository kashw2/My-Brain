.191 ^el-bt2

.192 ^el-nt3

.255 ^el-bt3

0 ^el-bn0

64 ^el-bn1

↑ boundaries = multiples of the block size (64) ^el-linelbl

Finding the block ^el-boxt0

block size = 256 − mask Octet
           = 64  (for /26)
Network   = host − (host mod block)
Broadcast = Network + block − 1 ^el-boxb0

192.168.1.200 / 26 ^el-boxt1

200 mod 64 = 8
Network   = 200 − 8  = .192
Broadcast = 192 + 63 = .255
→ 192.168.1.192 – .255 ^el-boxb1

.60 vs .70  (/26) ^el-boxt2

.60 → 60 − (60 mod 64) = .0
.70 → 70 − (70 mod 64) = .64
the .64 boundary splits them
→ different networks ^el-boxb2
