FINDING THE BLOCK

block size = 256 − mask Octet
= 64 for /26
Network = host − (host mod block)
Broadcast = Network + block − 1 ^el-card0-t

EXAMPLE:  .200 / 26

200 mod 64 = 8
Network = 200 − 8 = .192
Broadcast = 192 + 63 = .255
→ 192.168.1.192 – .255 ^el-card1-t

.60  vs  .70   ( /26 )

.60 → 60 − (60 mod 64) = net .0
.70 → 70 − (70 mod 64) = net .64
the .64 boundary splits them
→ different networks ^el-card2-t
