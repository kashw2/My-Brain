## Text Elements
Network Boundaries  (/26) ^el-title

A /26 network can only start on a multiple of 64. An address belongs to the block it lands in. ^el-sub

.0 – .63
network .0 ^el-b0-t

.64 – .127
network .64 ^el-b1-t

.128 – .191
network .128 ^el-b2-t

.192 – .255
network .192 ^el-b3-t

0 ^el-bn0

64 ^el-bn1

128 ^el-bn2

192 ^el-bn3

256 ^el-bn4

boundaries = multiples of 64 ^el-blbl

.200 lands here  →  network .192 ^el-ex

HOW TO FIND THE NETWORK

Round the address DOWN to the nearest
multiple of the block size (64 for /26)

network = host − (host mod 64) ^el-cardrule-t

WORKED:  .200 / 26

200 mod 64 = 8
200 − 8 = 192
→ network .192   ·   broadcast .255 ^el-cardex-t
