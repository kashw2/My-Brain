Scala is a compiled [[Static Typing|Statically Typed]], [[Object Orientated Programming|Object Orientated]] and [[Functional Programming|Functional]] Programming Language that is built upon the [[Java Virtual Machine|JVM]] that also supports compilation to [[JavaScript]] and to Native Binary via the [[Low Level Virtual Machine|LLVM]].

----

## Features

- [[Static Typing|Static Typing / Static Type Analysis]]
- [[For Comprehension]]
- [[Pattern Matching]]
- [[Kinds|Higher Kinded Types]]
- [[Implicits|Implicits / Givens]]
- Reflection
- Java Interoperability
- Type Inscription
